const int PIN_BLUE	= 4;

  pinMode(PIN_RED	, OUTPUT);

* Code Explanation
- /pinMode(pin, mode)/		: Takes a /pin/ and sets that pin be either an /OUTPUT/ or an /INPUT/ pin. More information about GPIO [[https://en.wikipedia.org/wiki/General-purpose_input/output][here]]
- /digitalWrite(pin, value)/	: Takes a /pin/ set the value that /pin/ to either /HIGH/ or /LOW/. /HIGH/ is 5v or on shields 3.3v. /LOW/ is for ground
- /delay(time)/			: Takes a /time/ in Mileseconds and pauses the program for that time.
